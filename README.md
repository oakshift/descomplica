# Descomplica

App simples de lembretes para poupar e descomplicar a vida: tarefas que se repetem (contas, papelada, IRS, compras), a regra das 48 horas para compras por impulso e um resumo de dicas.

- App: https://oakshift.github.io/descomplica/
- Os dados ficam num repositório privado à parte (`dados.json`), lido e escrito pela app com um token do GitHub guardado só no navegador.
- Os lembretes podem ser exportados em `.ics` para o Proton Calendar (ou outro calendário).
